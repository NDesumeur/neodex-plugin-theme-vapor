# Thème Vaporwave 95 pour NeoDex

Un vieux bureau d’ordinateur en pastel : fenêtres en relief, barres de titre dégradées, grille rose à l’horizon.

*English version: [README.en.md](README.en.md)*

S'installe depuis NeoStore, rayon **Thèmes et décors**, puis se choisit dans Paramètres › Apparence.

- Change les couleurs, les polices et les cadres de NeoDex. Le décor du fond reste celui que tu as choisi.
- Fonctionne sur PC et sur téléphone. Demande NeoDex 3.3.9 ou plus.
- Ne demande aucune autorisation et ne contient aucun code : rien ne vient d'Internet.

Avant NeoDex 3.3.9, ce thème était intégré à NeoDex. Il est maintenant à part pour garder NeoDex sobre de base.
